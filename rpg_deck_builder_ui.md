# RPG Deck Builder - UI Design Prompt (Stitch Optimized)

## Philosophy: Dark Fantasy & Tactical Clarity
This prompt is designed for Stitch to generate a high-fidelity, interactive battle interface for a dark fantasy roguelike deck builder. The design should feel polished like a modern TCG (Trading Card Game) with clear visual hierarchies.

---

### Screen: The Battle Board
**Objective:** Create a tactical 1v1 or 1vM (many) battle screen with a clear separation between player and enemy zones.

**Layout & Components:**
- **Central Battlefield:** A dark, atmospheric arena (e.g., a gothic dungeon floor) where enemy sprites/illustrations are centered. Each enemy has a clear HP bar and an "Intent Icon" above their head (e.g., a sword for attack, a shield for defend).
- **Player Stats Area (Bottom Left):** A stylized "Hero" portrait or badge. Display current HP as a vibrant red bar with numerical values (e.g., 80/80). Display current Energy as glowing blue mana crystals.
- **Hand Area (Bottom Center):** A row of interactive cards. Each card should have a "Hearthstone-style" mana crystal in the top-left, a central art box (using fantasy icons or silhouettes), a name banner, and a text box for the description.
- **Combat Log (Top Left):** A minimalist, translucent scrolling log showing recent actions (e.g., "You played Strike for 6 damage").
- **End Turn Button (Bottom Right):** A large, tactile "End Turn" button that glows when the player has no more valid moves or energy.

**Style & Vibe:**
- **Colors:** Deep charcoal and slate backgrounds. Use high-contrast accents: Crimson for HP/Damage, Tonal Spot Gold for rare elements, and Vibrant Blue for Energy/Mana.
- **Typography:** Serif headings for a classic fantasy feel (e.g., "Source Serif 4"), and clean sans-serif (e.g., "Inter") for numbers and descriptions to ensure readability.
- **Borders:** Use slightly rounded corners (8px) for cards and UI panels to feel modern but structured.
- **Imagery:** Dark fantasy theme. Images should be moody, gothic, and stylized.

**Interactive Cues:**
- Hovering over a card should scale it up and add a glowing blue border.
- Selected cards should have a golden highlight.
- Damage numbers should pop up as floating red text over targets.
